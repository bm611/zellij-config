# zellij-config

My zellij config: the `pills` layout plus the [zjstatus](https://github.com/dj95/zjstatus) status bar.

## Install (WSL / Linux / macOS)

```sh
git clone git@github.com:bm611/zellij-config.git
cd zellij-config && ./install.sh
```

`install.sh` backs up any existing `~/.config/zellij` and replaces the `__HOME__` placeholders in the layouts with your `$HOME`.
